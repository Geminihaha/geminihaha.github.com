## 🔧 1. 스와이프 레이어 회전 오류 수정 (`f91ef7c`)

**문제**
- "둘러보기"는 카메라가 아닌 큐브 그룹을 회전시키는 방식인데, 레이어 회전 계산이 월드 좌표 기준이라 둘러보기 후 스와이프 시 **화면에 보이지 않는 면의 레이어가 돌아가거나** 매칭 실패로 아무것도 안 돌아가는 현상 발생.
- 롱프레스 발동 시 `OrbitControls`(카메라)와 `rotateCubeFree`(큐브)가 **동시에 회전**하는 이중 회전 오동작.
- 2x2↔3x3 전환 시 `setInspectMode(true)`가 콜백 등록보다 먼저 호출되어 **둘러보기 버튼 active 상태가 풀림**.
- 스와이프 실패 시마다 둘러보기 버튼이 켜졌다 꺼지는 깜빡임.

**수정 (`js/controls.js`, `js/main.js`)**
- `handleLayerDrag()`를 **큐브 로컬 좌표계** 기준으로 재작성: 히트 노멀을 그룹 로컬로 변환하고, 로컬 축을 월드로 변환해 화면 투영 계산 → 둘러보기 후에도 보이는 면 기준으로 정확히 회전.
- 롱프레스/인스펙트 모드에서는 **OrbitControls를 비활성화**하고 큐브 직접 회전만 사용 → 이중 회전 제거.
- 롱프레스 감지 시간 180ms → **350ms** 로 늘려 일반 스와이프 중 오발동 방지.
- `initGame()`에서 inspect 상태 콜백을 **먼저 등록** 후 `setInspectMode()` 복원 → 버튼 상태 동기화.
- 모드 전환 시 **큐브 그룹 쿼터니언과 카메라 각도 유지** (거리만 재조정).
- 스와이프 실패 시 버튼 깜빡임 제거, 남은 드래그를 큐브 회전으로 자연 전환.

## ➕ 2. 줌 인/아웃 + 화면 자동 맞춤 (`4bbead9`)

**추가 (`js/main.js`, `index.html`)**
- 툴바에 **줌 버튼**(`➖` 축소 / `➕` 확대) 추가, `zoomBy(factor)`로 카메라 거리를 조절 (시점 각도 유지).
- `OrbitControls.maxDistance` 15 → **25** 확장.
- `updateCameraDistance()`를 **종횡비 기반 자동 맞춤**으로 개선:
  - 큐브 대각선 반경 + 수직/수평 반각 중 좁은 쪽 기준으로 거리 계산, 15% 마진.
  - 세로 화면(모바일 포트레이트)에서도 큐브가 화면에 전체 표시.
- 기기 회전/창 크기 변경(`resize`) 시 자동 재맞춤.

## ➕ 3. 롱터치 둘러보기 상태 인디케이터 (`6dd4efa`)

**변경 (`index.html`, `style.css`, `js/controls.js`, `js/main.js`)**
- 롱터치(롱프레스)로 둘러보기 중일 때 **둘러보기 버튼이 아니라 화면 상단 플로팅 배지**로 상태 표시: "🖐️ 둘러보기 중 · 손을 떼면 해제".
- 상태 콜백에 `fromHold` 플래그 추가 → 롱터치는 인디케이터, 수동 토글은 버튼 active에만 반영.
- 인디케이터는 `pointer-events: none`이라 터치를 방해하지 않음.

## 🐛 4. 스테일 컨트롤러 리스너 해제 (`0c41465`)

**문제**
- `initGame()`이 모드 전환/리셋 시 새 `CubeController`를 만들지만 **이전 컨트롤러의 이벤트 리스너를 해제하지 않아**, 구식 컨트롤러가 낡은 플래그(`isInspectMode=false`, 롱프레스 타이머)를 가진 채 이벤트를 계속 수신.
- 그 결과 둘러보기 버튼을 켠 상태에서 큐브를 돌리면 **구식 컨트롤러의 `onPointerUp`이 버튼을 꺼버리는** 현상 + 이중 회전.

**수정 (`js/controls.js`, `js/main.js`)**
- `CubeController.dispose()` 추가: 바인딩된 포인터 리스너 제거 + 롱프레스 타이머 취소.
- `initGame()`에서 새 컨트롤러 생성 **전에** 이전 컨트롤러 `dispose()` 호출.

## 🐛 5. 승리 감지 버그 수정 + 마침 버튼 (`14e789a`)

**문제**
- `checkFaceColorsUniform()`이 스티커 색을 `texture.uuid`로 비교했는데, 같은 색도 cubie마다 **새 텍스처 인스턴스**라 uuid가 모두 달라 `isSolved()`가 항상 false → **큐브를 완성해도 타이머가 계속 진행**.

**수정 (`js/cube.js`, `index.html`, `style.css`, `js/main.js`)**
- 텍스처에 `colorHex` 저장 후 색 비교를 **uuid → 색상값**으로 변경 → 승리 감지 정상화.
- **🏁 마침 버튼** 추가:
  - 섞기/스캔 후 활성화, 큐브 완성 감지 시 **초록 하이라이트(ready)** + 타이머 자동 정지.
  - 누르면 기록 저장 + 축하 모달, 미완성 상태면 shake 피드백.
- 기존 자동 모달 대신 **마침 버튼으로 완료 확정**하는 흐름으로 변경.

## 🚀 6. 반자동 큐브 스캐너 (촬영 + 탭 입력) (`c916d2e`)

**신규 (`js/scanner.js` 신규, `index.html`, `style.css`, `js/cube.js`, `js/main.js`)**
- 메인 툴바에 **📷 촬영 버튼** 추가 → 풀스크린 스캐너 모달 오픈.
- **`CubeScanner` 클래스**: 후면 카메라(`getUserMedia`) 스트림 + N×N 스티커 그리드 오버레이.
- 6면(U/D/L/R/F/B) 탭 + **면별 방향 가이드** 표시 ("위에서 보기 · 그리드 위쪽 = 큐브 앞면" 등).
- 각 셀을 탭해 6색 팔레트(빨/주/흰/노/초/파) + 지우개 ✕ 로 색 지정.
- 📷 캡처 버튼으로 카메라 프레임을 그리드 배경에 고정(참고용).
- 6면 모두 입력 시 **✅ 이 패턴으로 시작** 활성화.
- **`CubeModel.applyPattern()`**: 6면 스티커 패턴을 표준 면 표기법으로 cubie material에 매핑 → 실제 큐브 상태 재현 (2x2/3x3 지원).
- 패턴 적용 시 `hasScrambled=true` → 첫 이동부터 타이머 시작, 마침 버튼 활성.

**카메라 미사용 대응**: 카메라 권한 거부/미지원 환경에서도 수동 탭 입력만으로 사용 가능.

## ➕ 7. 캡처 후 다시 촬영 토글 (`465e5eb`)

**변경 (`js/scanner.js`, `style.css`)**
- 캡처 버튼이 **토글**로 동작: `📷 캡처` ↔ `🔄 다시 촬영`(주황 활성).
- 캡처 상태에서 버튼을 누르면 캡처 이미지를 지우고 **라이브 카메라로 복귀**.
- 면 전환/스캐너 닫기 시 캡처 자동 초기화.

## ➕ 8. 캡처 시 색 자동 입력 + 토글 (`bd140d5`)

**변경 (`js/scanner.js`, `index.html`, `style.css`)**
- **✨ 자동입력 토글 버튼** 추가 (기본값: 켜짐, 보라색 활성 표시).
- 켜져 있으면 캡처 시 **각 스티커 셀의 색을 자동 감지**해 그리드에 자동 입력.
- 감지 방식:
  - 캡처 프레임을 **정사각형 중앙 크롭** → 그리드 셀과 1:1 매핑.
  - 각 셀 **중앙 45%만 샘플링**해 평균 색 계산 (스티커 테두리/그림자 영향 최소화).
  - **HSV 색공간** 판별: hue로 빨강/주황/노랑/초록/파랑 분류, 채도 낮고 밝으면 흰색, 너무 어두우면 건너뜀 → 조명 차이에 강건.
- 자동 입력 후에도 잘못된 셀은 탭으로 수정 가능.

## 💡 참고 사항

- **카메라 권한**: 스캐너는 `getUserMedia`를 사용하며 HTTPS(개인 페이지 GitHub Pages)에서 동작합니다. 카메라 권한을 허용해야 합니다.
- **인식 정확도**: 조명이 밝고 균일할수록 자동 색 인식률이 높습니다. 그늘·반사가 있으면 자동입력을 끄고 수동으로 입력하세요.
- **색 판정 튜닝**: `js/scanner.js`의 `nearestColorKey()`의 임계값(`s < 0.22`, `bestD < 42` 등)과 샘플링 비율(`pad`, `sample`)을 조정해 인식률을 개선할 수 있습니다.
